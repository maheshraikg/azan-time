# Azan Time

Exact Azan and Namaz times, Qibla, Duas & Azkar, Ramadan timetable and a
Hijri calendar – a Flutter app for Android that works fully offline.

## Download

The newest test build is published by GitHub Actions on every push:

- arm64 (most phones): `releases/download/apk-latest/waqt-arm64.apk`
- universal: `releases/download/apk-latest/waqt.apk`

## Develop

```
flutter pub get
flutter analyze
flutter test
flutter build apk --release
```

Play Store text: [docs/play_store_listing.md](docs/play_store_listing.md).
